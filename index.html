Installing downloaded apps

Windows installer

Run the file and follow the steps. If Windows shows "Windows protected your PC", choose More info, then Run anyway. Windows shows this for apps from small developers that haven't paid for a signing certificate.

Windows portable

Nothing to install. Put the file in any folder and open it. To remove the app, delete the file.

Android APK

Open the downloaded file. Android asks you to allow installs from your browser the first time; turn it on, go back, and tap Install.
